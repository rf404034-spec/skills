# 雨中的觸碰

一支約 50 秒、沒有對白的 AI 短片，風格參考《銀翼殺手 2049》。

K 站在巨大的落地窗前發呆，窗外下著雨。一個全息虛影在房間各處閃現，時不時碰一下他。

## 工作方式

每一步做完，都先給你看結果，你確認之後才進下一步。

| 步驟 | 內容                                           | 狀態      |
| ---- | ---------------------------------------------- | --------- |
| 1    | 分鏡、提示詞、腳本                             | ✅ 完成   |
| 2    | 生成角色設定圖（K、虛影、房間），你挑選        | ⏳ 等 API |
| 3    | 生成 9 個鏡頭的關鍵畫面，你挑選                |           |
| 4    | 先用 Mini 試做影片，再用標準版出最終版，你挑選 |           |
| 5    | 調色、加黑邊、加閃爍特效、剪輯，給你看初版     |           |
| 6    | 配樂和音效，完成                               |           |

## 分鏡

整體色調：室內是昏暗的暖琥珀色，參考 K 那間狹小、水泥牆的公寓；窗外是冷青色加粉紫色霓虹，雨滴的影子投在牆上和臉上。

虛影的瞬間移動，是把很多個 3～5 秒的短鏡頭剪在一起，每個鏡頭開頭加閃爍和故障特效來做的。K 整支片幾乎不動，這樣他在每個鏡頭比較容易長得一樣。

| #   | 秒數 | 畫面                                               | 運鏡       |
| --- | ---- | -------------------------------------------------- | ---------- |
| s01 | 6    | 雨夜巨型城市，一棟野獸派大樓上有一扇亮著的窗       | 緩慢推近   |
| s02 | 6    | 室內大遠景：K 站在巨大落地窗前的剪影               | 靜止       |
| s03 | 5    | K 的側臉，雨滴影子在臉上流動，眼神放空             | 極慢推進   |
| s04 | 3    | 虛影在他身後的廚房角落閃現，又消失                 | 靜止加閃爍 |
| s05 | 4    | 虛影出現在他身旁，指尖輕碰他的肩膀，他沒有反應     | 靜止       |
| s06 | 4    | 特寫：K 的手貼在玻璃上，半透明的手疊上去，穿了過去 | 靜止       |
| s07 | 3    | 從背後拍的遠景：虛影在沙發上一閃而過               | 靜止加閃爍 |
| s08 | 5    | 近景：她從背後輕撫他的臉，他閉上眼                 | 極慢推進   |
| s09 | 7    | 收尾：K 獨自站在窗前，虛影不見了，淡出到黑         | 靜止       |

聲音：低頻合成器長音和雨聲貫穿全片；虛影每次閃現都配一個電子「嗞」聲；s08 配一段溫柔的高頻音色。

角色都是原創人物，氣質參考 K 和 Joi，但不是演員的臉。提示詞裡不寫片名和人名，避免被版權過濾擋下來。

完整的英文提示詞在 [`shots.json`](shots.json)，要改分鏡就改這個檔案。

## 設定 API

需要一把火山方舟 API Key，並在控制台開通 Seedance 2.0（含 Mini）和 Seedream。

把金鑰加到雲端環境設定（標題列的環境選單 → Edit → Network secrets 或環境變數），**不要貼在聊天裡**：

| 變數                   | 內容                                                        |
| ---------------------- | ----------------------------------------------------------- |
| `ARK_API_KEY`          | 方舟 API Key（必填）                                        |
| `ARK_VIDEO_MODEL`      | Seedance 2.0 的模型 ID 或接入點 ID                          |
| `ARK_VIDEO_MODEL_FAST` | Seedance 2.0 Mini 的模型 ID 或接入點 ID                     |
| `ARK_IMAGE_MODEL`      | Seedream 的模型 ID（不填就用 `doubao-seedream-4-0-250828`） |

設定好之後開一個新對話，告訴 Claude「繼續做 `video/rain-touch`，從第 2 步開始」。

## 腳本用法

```bash
# 生成 4 張角色設定圖，挑一張
python3 video/rain-touch/scripts/ark.py image k -n 4
python3 video/rain-touch/scripts/ark.py approve k video/rain-touch/output/images/<檔名>.png

# 關鍵畫面會自動帶上已選定的角色圖和房間圖當參考
python3 video/rain-touch/scripts/ark.py image s02 -n 4
python3 video/rain-touch/scripts/ark.py approve s02 <檔名>.png

# 影片：--fast 用 Mini 試做，不加就用標準版
python3 video/rain-touch/scripts/ark.py video s02 --fast
python3 video/rain-touch/scripts/ark.py approve s02 <檔名>.mp4

# 調色、黑邊、閃爍特效、剪輯 → output/final.mp4
python3 video/rain-touch/scripts/post.py

# 目前花了多少錢
python3 video/rain-touch/scripts/ark.py cost
```

每個指令都可以加 `--dry-run`，只印出要送出的內容，不會花錢。

生成的檔案都放在 `output/`，這個資料夾不會進 git。

## 費用估算

匯率以 1 人民幣約 4.4 新台幣粗估。

| 項目                                 | 數量      | 新台幣          |
| ------------------------------------ | --------- | --------------- |
| 生圖（Seedream）                     | 約 100 張 | 約 90～130      |
| 影片（Seedance，Mini 試做 + 標準版） | 約 200 秒 | 約 530～800     |
| 後期（ffmpeg）                       | —         | 0               |
| **合計**                             |           | **約 620～930** |

`ark.py cost` 印出的花費是按預設單價估的，實際以火山方舟控制台的帳單為準。

## 還沒驗證的部分

腳本寫完時還沒有 API Key，所以呼叫火山方舟的部分只用 `--dry-run` 檢查過送出的內容，還沒真的打過 API。第一次執行時要確認幾件事：

- Seedance 2.0 的模型 ID
- 參數是寫在提示詞裡（`--resolution 1080p --duration 5`），還是要放在請求的欄位裡
- 回應裡用量欄位的名稱

`post.py` 已經用測試影片跑過，調色、黑邊、閃爍特效和剪輯都正常。
